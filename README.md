# Python Projects

A collection of Python practice projects I built while learning software development. Each script is a small, standalone program that explores a different idea, from simple utilities to games.

## Projects

| File | Description |
|------|-------------|
| `Calculator_Program.py` | A calculator for basic arithmetic |
| `Imagedownloader.py` | Downloads images from the web |
| `Notepad.py` | A simple notepad-style text editor |
| `Number_Guessing.py` | A number guessing game |
| `PasswordGenerator.py` | Generates random passwords |
| `Racing.py` | A racing game that saves a high score |
| `Snake.py` | The classic Snake game |
| `Stars.py` | Star pattern / drawing practice |
| `functions.py` | Practice with Python functions |
| `learning.py` | General Python learning exercises |
| `assets/TexttoSpeech.py` | Converts text to spoken audio |
| `assets/Youtube.py` | YouTube-related script |

## How to run

1. Install [Python 3](https://www.python.org/downloads/).
2. Clone this repository:
   ```bash
   git clone https://github.com/Josiah-ui/python-projects.git
   cd python-projects
   ```
3. Run any script:
   ```bash
   python Snake.py
   ```

Some scripts use extra libraries. If you get an `ImportError`, install the missing package with `pip install <package-name>`.
